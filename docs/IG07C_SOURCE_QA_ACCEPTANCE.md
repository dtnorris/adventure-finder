# Exception-only source QA acceptance

IG-07C exercises AdventureFinder's public `af-catalog start` and `resume`
surface against the installed `af-data-pipeline` public routing and source
progression binaries. All acceptance roots and artifacts are disposable. The
fixtures contain only minimal structural page markers, headings, registry
entries, and an empty synthetic workbook.

## Clean control

The clean case supplies complete attributed source intent, an accepted
downstream-ready conversion receipt, explicit canonical destination, valid
single-file registry state, observed PDF-to-printed-page mapping, and a frozen
base binding. It reaches `BOUNDARY_EDITORIAL_REVIEW` without a routine source-QA
stop. A fresh-process repeat validates the same operation and review workspace
without another pipeline transition or any file mutation.

## Exception coverage

The actual public seams prove focused stops for:

- unresolved conversion page review and a non-downstream-ready receipt;
- unknown page mapping at the boundary-dossier QA gate;
- conflicting canonical Markdown bytes;
- missing or invalid source registry data;
- a canonical file already attributed to another source identity;
- segmented registration requiring manual operator adjudication;
- changed bound artifact bytes and changed operation-bound source intent; and
- a zero-exit child result that declares missing continuation files.

Pipeline routes retain their evidence, human-review instructions, warnings, and
inspection-only commands. Blocked diagnostics expose the refusing owner, stable
reason code, message, and one focused next action. Neither form authorizes a
silent retry, replacement source, reconstructed intent, provenance edit, or
exception acceptance.

## Authorized correction and restart

The recovery case pauses after a valid source-intake artifact is bound. Repeated
resume remains at the same registry-review gate and leaves the operation and
upstream bytes unchanged. The fixture then applies the explicit single-file
mapping through pipeline's public `af-source-register` command. A fresh-process
resume revalidates the changed registry evidence, reuses the byte-identical
canonical Markdown and source-intake bundle, and advances only the missing
dossier and editorial-handoff transitions.

## Negative authority

Sentinel executables prove the source driver never invokes freeze/import,
scoring preparation or execution, inference, provider or capacity tooling,
catalog-role mutation, promotion, Git, or remote execution. The generated
editorial ledger remains empty: boundary candidates, titles, ranges, parentage,
levels, Adventure IDs, dispositions, and approval remain human-owned.
